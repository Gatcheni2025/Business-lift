# Business Growth acceptance preview

Candidate base: `e7366ca65b381b7528c4801bf8e846ed354efaba` (PR #238). Audit-only branch; no production changes. The preview serves actual Admin assets on loopback, runs the actual acquisition service against the FakeDB regression adapter, and intercepts all browser network traffic. Google listings and provider acceptance are synthetic. Firebase Auth is mocked. No Firebase project, credentials, Zoho client, or Meta sender is initialized. The preview worker accepts only `@example.invalid` addresses and never calls a provider. The DB lives in memory and is discarded on close. It is not a Firestore integration or production-delivery test.

Run from a separate clean checkout with Node 22 or newer: `npm ci --ignore-scripts --no-audit --no-fund --prefix tools/admin-release`, `npm ci --ignore-scripts --no-audit --no-fund --prefix services/teyza-mobile-v39`, `cd tools/admin-release`, `npx playwright install chromium`, `node business-growth-preview.cjs`. Add `--check` for headless screenshots. Use synthetic sender `+27000000099` and `.invalid` addresses. Do not enter real contact details. Choose All matched prospects in work queue to see all demo states. To demonstrate direct Zoho queue, open a new prospect and choose its email invitation in Zoho email, review and queue. Click the preview-only Simulate Zoho acceptance button and Refresh send history; only simulated accepted email unlocks an eligible manual reminder. A pre-seeded welcome example is also available. External navigation is blocked in browser context, including WhatsApp/Zoho popups. For a genuine workflow, manually record sent only after actual send; in preview use synthetic outcomes. No live data or credentials are required. Close all preview windows to end the process.
