# Expanded catalogue image provenance

Created using the built-in image generation tool in two calls. Source images remain unchanged; frame metadata selects individual photographs at render time. They are illustrative product references with generic packaging.

Final project assets:

- `apps/teyza_shopper/assets/catalogue/food-drinks-expanded.png`
- `apps/teyza_shopper/assets/catalogue/care-household-expanded.png`
- `services/teyza-mobile-v39/catalogue-images/food-drinks-expanded.png` (identical copy)
- `services/teyza-mobile-v39/catalogue-images/care-household-expanded.png` (identical copy)

Both atlases are 1024 × 1536 pixels. Original atlases were retained. The source image files were copied into the GitHub-backed project; crop bounds live in catalogue.json and generated native metadata.
