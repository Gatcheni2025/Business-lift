# Business Expo workspace redesign

The workspace pages share `assets/workspace.css`, `assets/workspace.js`, and the shell/navigation generated by `scripts/build-workspace.py`. Edit page bodies under `ui/pages/` and titles/scripts in `ui/pages.json`, then run:

```powershell
python scripts/build-workspace.py
```

The login, signup and password-reset pages use the same stylesheet. `assets/styles.css` remains for the public landing page.

## Backend architecture

The workspace is now PHP-backed. Firestore and Firebase Cloud Functions were removed from the application data layer.

Firebase Authentication remains for sign-in only. Browser modules call `js/api-client.js`, which obtains a Firebase ID token and sends it to same-origin PHP endpoints in the `Authorization` header. PHP validates the token and reads/writes protected server-side storage.

```text
Browser → Firebase Auth → Business Expo PHP API → protected storage
```

Main APIs:

```text
api/profile.php
api/products.php
api/orders.php
api/customers.php
api/dashboard.php
api/settings.php
api/social-connections.php
api/social-callback.php
api/sales-chat.php
```

## Workspace persistence

The following pages now persist through PHP:

- business profile
- products and image uploads
- orders
- customer activity
- dashboard metrics
- seller onboarding
- delivery settings
- shop settings
- payment preferences
- partner network profile
- selling connections

The PHP API keeps page code independent of the storage implementation. The current storage is protected JSON files; it can later be swapped for MySQL without returning the frontend to Firestore.

## Uploads

Product images are compressed in the browser before upload and resized/compressed again by PHP when GD is available. Files are stored under `uploads/products/`; script execution is blocked in the upload tree.

## Security

- private workspace endpoints require a verified Firebase ID token
- `storage/.htaccess` blocks direct access to PHP data files
- `uploads/.htaccess` prevents uploaded scripts from executing
- bank account numbers and PayFast secrets are encrypted with AES-256-GCM using `BUSINESS_EXPO_DATA_KEY`
- OAuth secrets and provider tokens stay server-side

## Deployment

This project should now be deployed to the PHP-capable host serving `https://www.businessexpo.co.za` rather than deployed as a Firestore/Cloud Functions backend.

Required runtime variables and callback URLs are documented in `PHP-BACKEND-SETUP.md`.
